A block theme for the Northstar documentation landing page.

== Description ==

Northstar is a Full Site Editing theme. The home page is assembled from seven editable block patterns: hero, features, stats, testimonials, pricing, FAQ and call to action. Colors, type and spacing are defined once in theme.json and editable in the Site Editor.

== Installation ==

1. Upload the theme in Appearance > Themes > Add New > Upload Theme.
2. Activate it.
3. In Settings > Reading, set the homepage display to "Your latest posts" (the front-page template renders the landing page) or choose a static page.
4. Set the Site Title to "Northstar" in Settings > General.
