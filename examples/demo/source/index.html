Frequently asked questions

Which Markdown formats do you support?

CommonMark, GitHub-flavored Markdown, and MDX. Front matter is optional.

Can I host the docs on my own domain?

Yes. Point a CNAME at Northstar and we provision the certificate automatically.

Is there a free plan?

The Starter plan is free forever for one project with public docs.

How do pull-request previews work?

Every pull request gets its own preview URL, posted as a comment on the PR.
