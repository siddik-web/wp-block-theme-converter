# Theme Quality Scripts

`doctor.mjs` is an umbrella runner that executes all five theme-quality checks in sequence and prints a pass/fail summary table.

## Usage

```
node scripts/doctor.mjs path/to/theme
```

If no path is given, it defaults to the current working directory.

## What it runs

| Script | Checks |
|---|---|
| `check-theme-structure` | Requires `style.css` and `templates/index.html`, a complete `style.css` header, resolvable template-part / pattern / palette-color references, and `php -l`-clean PHP (skipped with a warning if `php` is not installed) |
| `validate-theme-json` | Validates `theme.json` (and `styles/*.json` variations): version, `$schema`, settings, hardcoded colors (hex and `rgb()`/`hsl()`…), font files, `templateParts`, and `customTemplates` |
| `lint-block-markup` | Lints HTML/PHP in `templates/`, `parts/`, `patterns/` for hand-written inline styles (styles generated by block supports are allowed), `<style>`/`<script>` tags, unescaped PHP, and block delimiter mismatches |
| `check-patterns` | Verifies block pattern PHP files have required header fields (Title, Slug, Categories), slugs namespaced with the theme's Text Domain, and no duplicate slugs |
| `check-i18n` | Scans PHP files for unwrapped user-facing strings, hardcoded text in pattern markup, double-escaping, missing text domains, and text domains that don't match `style.css` |

## Exit codes

`doctor.mjs` exits `0` only when all five scripts pass. Individual scripts exit with the number of failures (capped at 127). All scripts are pure Node.js stdlib — no `npm install` required.

## Tests and the golden theme

```
node --test scripts/tests/*.test.mjs        # regression tests for every check
node scripts/build-golden-theme.mjs         # re-render examples/_generated/landing-page-theme from templates/
node scripts/build-golden-theme.mjs --check # exit 1 if the committed golden theme is stale
```
